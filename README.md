# 2026.1_PA1_CD_RACHAMAIS

Aplicação desenvolvida em equipe durante projeto acadêmico, voltada para a organização e divisão de despesas em atividades realizadas em grupo, como viagens e outros eventos.

O aplicativo permite que usuários participem de grupos, registrem e organizem despesas e acompanhem a divisão dos valores entre os participantes.
